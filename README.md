## Stella Dash
**This is a 2d Platformer game inspired by the hit game Super Mario.**
- There are five levels. You travel through 3 seasons: summer, winter, and fall.
- Use "A" to move left, "D" to move right, and press the "Spacebar" to jump.
- You must collect **all the coins** to advance to the next level
- You have _Three lives_. Spikes are instant kill, and Drilly deals one tick per touch. Three tick == death
- There are also no checkpoints in each level T-T

**I spent ~15 hours making this game, so I hope you all enjoy playing it ^_^.**
